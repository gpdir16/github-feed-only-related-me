# github-feed-only-related-me
Show only activity directly related to you in your GitHub home feed. (hide activity from people you follow)

## How to install

### 1. Install the UserScript engine to your browser

Because this project is Usescript, you will first need the Usescript engine in your browser. If you already have one, skip to the next step.

You can use Violentmonkey, Tampermonkey, etc. and below are the installation links for the recommended engines.

- for Firefox, Librewolf: [Violentmonkey via Firefox Addons](https://addons.mozilla.org/ko/firefox/addon/violentmonkey)
- for Helium, Brave, Ungoogled Chromium: [Violentmonkey via Chrome Web Store](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)
- for Safari: [Userscripts via Apple App Store](https://apps.apple.com/us/app/userscripts/id1463298887)

### 2. Add this script
Just open the link.
- https://github.com/gpdir16/github-feed-only-related-me/raw/refs/heads/main/github-feed-only-related-me.user.js
